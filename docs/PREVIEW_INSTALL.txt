SPIKE · предварительная тестовая версия · Apple Silicon

УСТАНОВКА
1. Откройте скачанный DMG.
2. Перетащите SPIKE.app на Applications в этом окне.
   Перед заменой предыдущей версии выйдите из неё через меню SPIKE.
3. Откройте SPIKE из «Программ». После установки образ можно извлечь.
Xcode, исходники и Terminal для установки не нужны.

ПЕРВЫЙ ЗАПУСК
Эта предварительная версия имеет локальную ad-hoc подпись; Developer ID и
нотарификации Apple пока нет.
Если macOS сообщает «Apple не удалось подтвердить…», после попытки открытия:
Системные настройки → Конфиденциальность и безопасность → «Открыть всё равно»
рядом со SPIKE. Подтвердите открытие, если доверяете источнику загрузки.
Точный текст зависит от версии macOS. Появление кнопки контролирует система.
Инструкция Apple: https://support.apple.com/102445

Если появляется только «Не удаётся открыть программу…» и кнопки исключения нет,
это пока не диагностированный отказ запуска. Эта упаковка не гарантирует его
исправления. При желании передайте разработчику текст ошибки и версию macOS.

КАК ПОЛЬЗОВАТЬСЯ
SPIKE появляется у верхнего края экрана, без отдельной иконки в Dock.
Наведение раскрывает его: Now Playing слева, Mirror справа.
ПКМ → «Настройки SPIKE…»: внешний вид, своя картинка и аудиовизуал.
В Mirror короткий клик по preview сохраняет фото, удержание начинает видео
со звуком микрофона, следующий короткий клик останавливает запись.
Файлы сохраняются на Desktop или в папку, выбранную в настройках.
Выход — пункт «Выйти…» в меню SPIKE.

РАЗРЕШЕНИЯ И ДАННЫЕ
Камера запрашивается при входе в Mirror, микрофон — только при начале видео.
Визуал может запросить общий выходной звук Mac; аудиосэмплы остаются в памяти.
Для приоритета Music/Spotify разрешение Automation запрашивается явным пунктом
«Разрешить Spotify и Music…», когда нужный плеер запущен.
Сохранение на Desktop может отдельно потребовать доступ к папке.
Фото и видео локальные; отправки их в сеть в приложении нет.

Это кандидат для внешней проверки, не подтверждённая совместимость со всеми Mac
и версиями macOS. Сборка только для Apple Silicon (arm64), не для Intel.
Автоматическое обновление и автозапуск в этой версии не добавлены.
